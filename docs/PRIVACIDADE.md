# ClipFlow Studio — Política de Privacidade

Última atualização: 23 de outubro de 2026

O ClipFlow Studio é um aplicativo que roda **no computador do próprio usuário**. Ele não tem servidor próprio na
internet e não envia dados para os desenvolvedores.

## Dados do Google / YouTube

Quando o usuário conecta a conta do YouTube, o ClipFlow usa os **Serviços de API do YouTube** com duas permissões:

- `youtube.upload`: enviar ao canal do usuário os vídeos que ele mesmo escolher, com título, descrição, tags e
  agendamento definidos por ele;
- `youtube.readonly`: ler o nome e a imagem do canal conectado, só para mostrar ao usuário qual canal está em uso.

O token de autorização fica salvo **apenas no computador do usuário** (pasta de dados do ClipFlow). Ele não é
compartilhado com terceiros, não é vendido e não é usado para publicidade. O ClipFlow não lê, apaga nem altera
outros vídeos, comentários ou dados do canal.

## Outros dados

Vídeos, transcrições, cortes e configurações ficam na pasta de dados do ClipFlow no computador do usuário. O
usuário pode apagá-los a qualquer momento pelo próprio app ou apagando a pasta.

## Como revogar o acesso

- No ClipFlow: aba **Publicar › Desconectar** (revoga o token e apaga a cópia local).
- No Google: [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## Termos de terceiros

Ao usar a publicação no YouTube, o usuário também concorda com os
[Termos de Serviço do YouTube](https://www.youtube.com/t/terms) e com a
[Política de Privacidade do Google](https://policies.google.com/privacy).
